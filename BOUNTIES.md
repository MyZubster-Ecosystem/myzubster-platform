# Bounties — MyZubster Platform

This repository follows the canonical [MyZubster Bounty System](https://github.com/MyZubster-Ecosystem/myzubster/blob/main/BOUNTIES.md).

## Eligible scope

Platform bounties may cover legacy-module consolidation, API/service cleanup, tests, security hardening, documentation and migration into the current core architecture.

## Acceptance

A task must identify the current source of truth, avoid duplicating core behavior without a migration plan, and include tests/evidence appropriate to the change.

## Reward truth

MYZ in the current core platform is an internal reward/accounting ledger. A PR/merge is not proof of external payment; external XMR/token settlement requires independent evidence.

## Issues

Use this repository's GitHub issues and link implementation evidence to the bounty issue.
